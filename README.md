# Shrinidhi Saravanan — Personal Portfolio

A responsive, single-page personal portfolio for Shrinidhi Saravanan, a second-year B.E. Biomedical Engineering student at KPRIET aspiring to become a Software Developer. The site uses a soft pink and lavender palette and covers About, interests, projects, education, certifications, and contact.

## Files

- `index.html` — semantic page structure and content
- `style.css` — responsive layout, theme, illustration, and motion styles
- `script.js` — mobile navigation, scroll reveals, and current-year footer

## Run locally

Open `index.html` in a modern browser. The page works without a build step. Google Fonts are optional; system fallbacks are included.

## Content accuracy

The interests shown are based on the information provided: Software Development, AI in Healthcare, and Biomedical Instrumentation. No project or certification was listed because none was present in the connected public GitHub repositories at the time this portfolio was prepared. The current public repository had only its initial README commit.

## Publish with GitHub Pages

Place these files in the root of a public GitHub repository. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save. GitHub Pages will then publish the site at `https://shrinidhisaravanan18.github.io/shrinidhi-portfolio/`.
